# PASM v0：点级联合匹配与 Patch 内重采样

## 1. 目的与边界

v0 要验证的核心假设是：在每张图固定 512 个采样点的计算预算下，使用图像对联合信息能够让采样点逐轮向真实可匹配区域集中。

v0 的设计边界如下：

- Patch 是采样预算和区域管理单位，不是匹配单位。
- 所有采样点进行全局点级匹配；不建立 Patch 对，不使用 Patch 对 Top-K 限制匹配范围。
- 点只在所属 Patch 内重新采样，不跨 Patch 移动。
- Patch 之间通过下一轮采样预算迁移实现全图层面的资源调整。
- 暂时使用冻结 LoMa 描述子作为局部特征；它只用于过渡，后续将由双图条件化描述子替代。
- 暂不实现图像对拒绝、动态语义教师、VPR 教师、dustbin、显式成功点记忆和可学习采样器。
- 暂不以超过 LoMa 为目标；先确认多轮重采样本身是否产生正确的收敛趋势。

## 2. 图像、语义 Patch 与管理 Patch

输入图像统一缩放到 `518×518`。冻结的 DINOv2 输出 `37×37` 个 token，用于提供语义特征。

采样管理 Patch 使用独立的 `16×16` 网格，即每图 256 个管理 Patch。管理 Patch 不等同于 DINO token：每个管理 Patch 通过对其覆盖范围内的 DINO token 聚合，获得对应的语义上下文。

采用 `16×16` 网格的原因是每图固定 512 点，初始阶段要求所有 Patch 获得相同数量的点，因此每个管理 Patch 恰好分配 2 点。

## 3. 双图条件化语义与局部特征

### 3.1 语义分支

两张图的 DINO token 经过一层共享的双向 Cross-Attention，得到包含对侧图像信息的语义 token。聚合后，每个管理 Patch 都有一个双图条件化语义向量。

该语义向量用于两件事：

1. 评价该 Patch 在当前图像对中是否值得持续探索；
2. 为该 Patch 内的点对评分提供双图上下文。

语义分支不在第一轮删除任何 Patch；它仅在后续预算迁移时与点级匹配反馈共同发挥作用。

### 3.2 局部分支

LoMa 输出稠密局部描述子图。每个采样点从该图中双线性读取一个 LoMa 描述子。

v0 中 LoMa 描述子不是单独完成匹配的最终表示：点对边分数同时使用 LoMa 的局部相似度和两点所属 Patch 的双图条件化语义支持。后续版本将把 LoMa 替换为自训练的双图条件化局部描述子。

## 4. 初始化

第 0 轮中，每张图的每个管理 Patch 使用分层随机或 Sobol 方式采样 2 个点：

```text
16 × 16 个管理 Patch × 每 Patch 2 点 = 每图 512 点
```

初始化不依据 DINO 分数或单图局部显著性删减区域，确保图像所有区域都有首次被探索的机会。

## 5. 全局点级匹配

设两图当前轮的点集分别为 `A={a_i}` 和 `B={b_j}`，二者均有 512 个点。

1. 为每个点读取 LoMa 描述子和所属管理 Patch 的联合语义向量；
2. 对所有 `512×512` 个点对计算边分数；
3. 边分数由局部 LoMa 相似度和双图语义支持共同组成；
4. 对完整边分数矩阵使用 dual-softmax，得到软匹配边权；
5. 不在此处建立固定点对，也不将点限制到任何预设 Patch 对。

点 `a_i` 的即时质量由其最强、最明确的匹配边决定。若一个点对多个目标都相似，dual-softmax 会降低每条边的共同支持，因此该点不会被误认为高质量点。

## 6. Patch 价值与预算迁移

每个 Patch 的下一轮价值由以下两部分共同决定：

```text
Patch 价值 = 双图联合语义价值 + Patch 内点的边质量反馈
```

其中：

- 双图联合语义价值来自 DINO Cross-Attention 输出；
- 点级反馈由该 Patch 内采样点的即时质量聚合得到；
- 两者使用归一化后相加，不额外引入预算分类器。

这样，一个语义上确实有价值但首轮随机点没有踩中的 Patch 不会立刻失去探索机会；而连续产生清晰高质量边的 Patch 会逐步获得更多点。

每一轮都保持每图总点数为 512。Patch 的最低点数随迭代轮次变化：

1. 第 0 轮固定每 Patch 2 点，保证全图首次探索；
2. 第 1 轮（必要时连同第 2 轮）给每个管理 Patch 至少 1 个基础探索点，再按 Patch 价值分配剩余预算；
3. 从允许淘汰的轮次开始，Patch 最低点数改为 0，预算完全按当前 Patch 价值重新分配；
4. 始终使用每 Patch 点数上限，防止预算塌缩到极少数区域。

v0 默认在第 2 轮开始允许最低点数为 0，即先完成一轮全面探索和一轮保底重采样，再允许低价值 Patch 自然淘汰。最低点数切换轮次和每 Patch 上限都必须写入配置；上限默认暂设为 4，后续可直接调整为更大的值，无需修改算法逻辑。

## 7. Patch 内重采样

对于获得 `n` 个点预算的 Patch，不保留旧坐标作为永久状态，而是在 Patch 内重新生成 `n` 个位置。

采样分布由两部分组成：

```text
Patch 内采样分布 = 均匀探索部分 + 高质量点邻域部分
```

- 均匀探索部分保证不会每轮重复同一批坐标；
- 高质量点邻域部分以本轮高质量点为中心生成带扰动的新点；
- 扰动始终裁剪在所属 Patch 内；
- 高质量边会让下一轮点分布在其附近更密集；
- 低质量点不会成为重采样中心。

因此，v0 不把图像匹配当作凸优化问题，也不让点沿梯度移动。位置的改进来自采样分布的逐轮收缩：Patch 间由预算迁移修正，Patch 内由局部重采样修正。

## 8. 迭代与输出

总共使用 3 轮点集：

```text
第 0 轮：每 Patch 固定 2 点的均匀探索
第 1 轮：每 Patch 至少 1 点，根据第 0 轮的语义与边反馈调整预算并重采样
第 2 轮：允许 Patch 获得 0 点，再次调整预算并重采样，随后输出匹配
```

每一轮均重新计算完整的全局 `512×512` 点级匹配矩阵。上一轮的边关系只影响下一轮的采样分布，不会被锁定为粗匹配结果。

最终使用 mutual matching 输出数量可变的点级匹配、原图坐标和匹配置信度。

## 9. 单阶段训练

v0 使用 MegaDepth/SfM 几何监督，DINOv2 和 LoMa 均保持冻结。仅训练双向 Cross-Attention 和 Patch 价值头，并在全部轮次上联合施加损失。

### 9.1 几何标签

- 点级正标签：将 `A` 中采样点利用深度、相机内参和位姿投影到 `B`；`B` 中足够接近投影位置的采样点为正对应。
- 无可靠深度、出界、遮挡或深度矛盾的几何位置一律标为 `ignore`。
- Patch 正区域质量：统计该管理 Patch 中可可靠投影像素的覆盖度，作为该 Patch 的相对采样价值监督。

不构造 dustbin 标签，也不将所有未采到正点的位置简单视为负例。

### 9.2 损失

v0 只使用两类损失：

```text
总损失 = 点级匹配损失 + Patch 价值分配损失
```

- 点级匹配损失：监督可靠几何正点在全局点级匹配矩阵中的分配概率；无正点邻居的行或列忽略。
- Patch 价值分配损失：鼓励有限的预算优先分配给具有可靠几何正区域的 Patch，而不是单独训练“增加/保持/减少”的分类器。

采样规则在 v0 中是固定的，因此它不是严格意义上对随机采样路径反向传播的端到端采样器；但语义、点级评分和预算价值在同一阶段共同训练。可学习采样分布留给后续版本。

## 10. 验证标准

v0 的成功不以与成熟 LoMa 的直接胜负判定，而以以下现象为准：

1. 第 0 轮到第 2 轮，几何正确匹配数和内点率总体提高；
2. 高质量区域获得更多采样点，但不会塌缩到少数 Patch；
3. 点的可视化能够显示其向双图真实重叠区域逐轮集中；
4. 语义价值较高但首轮点质量较低的 Patch 仍保有后续探索机会；
5. 所有匹配始终来自全局点级矩阵，而非预先建立的 Patch 对。

## 11. 明确不属于 v0 的内容

- Patch 对筛选、Top-K Patch 对或 Patch 对预算；
- 单图关键点检测器；
- 跨 Patch 点移动；
- 拒绝头、动态物体处理、VPR/动态语义教师；
- dustbin 与不可匹配分类；
- 显式长期点状态、成功点永久保留；
- 自定义双图条件化局部描述子；
- 可学习的随机重采样策略或复杂多阶段训练。
