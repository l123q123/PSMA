# 九组相对位姿评测设计

对已完成的九组留出匹配结果进行离线相对位姿评测，不重新选点或匹配。每组从 `result.npz` 的 LoMa 互相匹配点估计基础矩阵对应的相对位姿；估计阶段只用匹配坐标与相机内参，MegaDepth 深度和真值位姿只用于误差计算。

对两张图分别用其内参归一化像素坐标，以归一化阈值执行 OpenCV 五点法 RANSAC 估计 E，再以 `recoverPose` 得到 A→B 的旋转和平移方向。真值使用 `inv(cam2world_b) @ cam2world_a`。每组输出匹配数、RANSAC 内点数、旋转误差、平移方向误差、最大姿态误差；汇总输出 pose AUC@5°、@10°、@20° 和中位误差。少于五个匹配或 RANSAC/recoverPose 失败的组记为失败并赋 180°，不静默丢弃。
