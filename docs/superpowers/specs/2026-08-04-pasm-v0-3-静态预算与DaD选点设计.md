# PASM v0.3：静态联合预算与 DaD 局部选点设计

## 目标

将当前 v0.2 的三轮重采样闭环收缩为一次静态推理：PASM 使用双图联合语义为每张图的管理 Patch 分配点预算，DaD 使用成熟的单图检测偏好在各 Patch 内选择精确特征点，随后由完整 LoMa-B128 完成描述和匹配。

本版本要验证的核心问题是：在不依赖三轮反馈的情况下，**双图联合的 Patch 预算是否能提升成熟 LoMa/DaD 局部特征匹配器的选点质量**。

## 已知实验结论与版本边界

- v0.2 的三轮 LoMa 闭环在 9 组具有有效几何真值的留出图像对上，6px 几何内点率约为 46.1%，低于静态语义基线的约 60.7%。
- 因此 v0.3 不保留锚点、跨轮反馈、重采样和三轮预算更新。
- v0.3 不重新训练 PASM；直接复用当前 v0.2 检查点中训练好的双图 Patch 价值头。
- v0.3 不训练 DaD 或 LoMa；两者均为冻结的成熟模型。
- v0.3 的目标是建立强而清楚的静态组合基线，而非解决后续端到端局部选点训练问题。

## 总体流程

对一对输入图像，固定缩放到 `518×518`：

1. 冻结 DINOv2 提取两图 token；PASM 双图语义编码器输出 A/B 图每个管理 Patch 的联合价值 `V_A`、`V_B`。
2. 按 `V` 和现有预算规则为各图 16×16 个 Patch 分配预算；每张图总计恰好 1024 点，每个 Patch 预算范围为 0～20。
3. 冻结 DaD 一次性对整张图输出 `518×518` 稠密检测分数图，并按 DaD 原生 `3×3` NMS 与亚像素 refinement 得到候选点。
4. 每个 Patch 仅从自身候选点中选取与其预算相同数量的 DaD 高分点；DaD 不单独决定区域预算。
5. 若某 Patch 的 NMS 峰值数量少于预算，则从该 Patch 内尚未使用的稠密 DaD 分数位置按从高到低补齐；补齐点不会重复，且仍位于该 Patch 内。
6. 将两图各 1024 个点送入完整冻结 LoMa-B128，获得描述、Transformer 匹配、互为最强对应和 LoMa 连续置信度。

## 职责划分

| 模块 | 负责内容 | 不负责内容 |
| --- | --- | --- |
| PASM 双图语义价值头 | 利用两张图联合语义决定每个 Patch 分配多少点 | Patch 内具体坐标 |
| DaD 检测器 | 在给定 Patch 内按本身的角点/局部可区分性偏好选择坐标 | 判断该 Patch 是否值得分配预算 |
| LoMa-B128 匹配器 | 对已选坐标描述并做两图 Transformer 匹配 | 主动检测额外点、修改 Patch 预算 |

该分工避免了两种退化：

- 不是 DaD 全图检测后再被动筛选，因此 PASM 高价值区域一定得到与预算相符的选点机会；
- 不是在小 Patch 裁图上各自运行 DaD，因此 DaD 的全图感受野、尺度、NMS 与亚像素机制保持不变。

## Patch 内 DaD 选点规则

### 输入和输出

输入：单图 DaD 稠密分数图、全图 NMS 候选坐标及其 DaD 分数、PASM 分配的 `[256]` Patch 整数预算。

输出：恰好 `[1024, 2]` 像素坐标、对应 `[1024]` Patch 索引和可选 `[1024]` DaD 分数。

### 选点顺序

对每个预算大于零的 Patch：

1. 取全图 DaD 原生 NMS 产生且中心属于该 Patch 的候选点。
2. 按 DaD 分数降序保留前 `budget[p]` 个；此处可使用 DaD 的原生亚像素坐标。
3. 若数量不足，扫描该 Patch 内的稠密 DaD 分数栅格，跳过已被 NMS 阶段选过的整数位置，按分数降序补齐。
4. 补齐坐标采用栅格中心坐标，不做额外手工启发式或额外 NMS。

所有输出点必须落在 `[0, 518)` 且其所属 Patch 与输出 Patch 索引严格一致。由于预算之和恒为 1024，输出总点数也恒为 1024。

## 推理模式和对照

新增两个 v0.3 推理模式，使用同一个 PASM v0.2 检查点和同一个 LoMa-B128 权重：

- `dad_global`：不使用 PASM；DaD 在整图全局选 1024 点，完整 LoMa 匹配器匹配两图点集。
- `pasm_dad`：PASM 静态双图预算 + 每 Patch DaD 选点，完整 LoMa 匹配器匹配两图点集。

保留现有 `static_semantic` 和 `iterative_loma` 兼容性，v0.3 新实验默认使用 `pasm_dad`。`pasm_dad` 与 `dad_global` 是 v0.3 的关键公平对照：若前者稳定更好，才能说明双图联合预算本身提供了价值。

## 输出、评测与可视化

每次推理继续在独立输出目录保存：

- `result.npz`：最终匹配点、LoMa 置信度、Patch 索引、Patch 预算、DaD 点分数和模式名；
- `points.png`：两图上的最终选点分布；
- `matches.png`：全部 LoMa 匹配连线；
- `high_confidence_matches.png`：LoMa 置信度不低于 0.6 的连线。

对 MegaDepth 正图像对，沿用直接深度投影的 3px/6px 几何内点率、内点数量和高置信度内点率。速度评测应将模型加载排除在外，在同一进程中预热后分别记录 `dad_global` 与 `pasm_dad` 的单对推理时间。

## 实现范围

新增一个专门的 DaD 选点适配模块；扩展当前推理入口以加载冻结 DaD、选择 v0.3 模式并保存 DaD 相关数据；新增覆盖预算、Patch 归属、补齐和模式路由的最小单元测试；README 新增中文 v0.3 命令与对照说明。

不改动：PASM 训练流程、质量教师缓存、质量头训练、三轮闭环的旧实现逻辑、现有 v0.2 输出目录。

## 验收标准

1. `pasm_dad` 与 `dad_global` 在同一输入下均输出每图恰好 1024 个不重复、边界内点。
2. `pasm_dad` 中每个 Patch 的实际点数与 PASM 预算完全一致；预算为 0 的 Patch 不得输出点。
3. Patch 内点优先来自 DaD 原生 NMS 峰；只有数量不足时才使用稠密分数补齐。
4. 两个模式均能用本地 `loma_B128.pth` 与本地缓存的 `dad.pth` 离线运行，不触发下载。
5. 新增测试与现有项目测试均通过。
6. 使用至少 9 组未参与训练清单的同场景 MegaDepth 图像对比较 `dad_global` 与 `pasm_dad`，再基于几何统计判断 v0.3 是否有效。
