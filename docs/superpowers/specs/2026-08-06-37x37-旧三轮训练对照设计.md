# 37×37 旧三轮训练逻辑对照设计

## 目的

验证旧版 `main_6px_1024_60.pt` 表现较好的原因，排除 DaD、完整 LoMa 匹配器和质量教师的影响。实验仅将旧版三轮训练流程适配到 DINO 原始的 `37×37` token 网格。

## 明确不包含的模块

- 不使用 `FrozenDaDDetector` 或 DaD 选点。
- 不调用完整 LoMa matcher。
- 不使用 v0.4 的离线 Patch 教师缓存、质量头、`value_only` 模式或 37×37 静态 DaD 推理入口。
- 不改动已有 v0.3 / v0.4 训练、推理与评测行为。

冻结的 LoMa `DeDoDeDescriptor` 仅用于生成单图稠密描述子图；它不是 LoMa 的完整匹配器。

## 配置

```text
图像尺寸：518×518
管理 Patch：37×37（共 1369 个）
总采样预算：1024 点 / 图 / 轮
迭代轮数：3
第 2、3 轮 Patch 最低点数：0
每 Patch 点数上限：20
几何阈值：6 px
几何支持采样间隔：2 px
```

首轮无法照搬旧版“每 Patch 固定 4 点”，因为 `1369 > 1024`。因此使用唯一必要适配：在 1369 个 Patch 中均匀、无放回地选择 1024 个 Patch，并在每个被选择 Patch 内随机采 1 点。未选 Patch 的首轮预算为 0。

## 每轮前向流程

1. 冻结 DINOv2 提取两图的 1369 个 token。
2. 冻结 LoMa 描述子网络提取两张单图的稠密描述子图。
3. 唯一可训练模块 `PairSemanticEncoder` 用一层共享双向 Cross-Attention 产生两图条件化 Patch 语义与 Patch value。
4. 在当前采样点位置从两张冻结描述子图读取局部描述子。
5. 每一对当前点计算 `局部描述子余弦相似度 + 所属 Patch 语义余弦相似度`，经 dual-softmax 得到全局点级边权。
6. 前两轮从互为最佳、边权超过锚点阈值的点对中保留锚点。
7. 用 `Patch value + 点级边反馈 + 锚点支持` 分配下一轮的 1024 点预算；锚点原样保留，其他点在所属 Patch 内重采样。

第 3 轮只生成最终点级边权，不再重采样。

## 训练监督

每一轮、每一方向均计算并平均：

```text
L = L_match + L_value
```

- `L_match`：由 MegaDepth 深度、内参和位姿将当前源采样点投影至另一图，再监督它在当前目标采样点中应对应的列。
- `L_value`：将可靠几何投影点按 37×37 Patch 聚合成归一化支持分布，监督 Patch value 的归一化分布。

三轮损失均参与反向传播；重采样坐标、锚点选择和预算分配是离散步骤，使用 `detach`，不对其本身求导。优化器只更新 `PairSemanticEncoder`。

## 新入口与输出

新增独立训练入口，例如 `pasm_v0.train_legacy37`，使用独立配置函数与独立检查点前缀。训练完成后，新增对应推理/评测入口或兼容既有旧式 `PasmV0` 推理，输出：

- 三轮采样点分布图；
- 最终直接 dual-softmax 匹配图；
- 九组 held-out 几何汇总（匹配数、3/6 px 内点率、6 px 覆盖率）。

不输出 DaD 或完整 LoMa matcher 的结果，避免评价对象混杂。

## 最小验证

1. 37×37 首轮恰好采 1024 点，Patch 不重复，且所有坐标在边界内。
2. 三轮流程在随机张量与小型伪特征上可前向、反向。
3. 训练入口不导入或实例化 DaD 和完整 LoMa matcher。
4. 运行现有测试中受改动影响的采样、管线和 CLI 测试。

## 成功判据

与现有 v0.4 静态 DaD 路线分开比较。首先观察：Patch value 是否更接近几何支持热图、三轮后内点率/覆盖率是否优于单轮静态语义基线。即使未超越旧 16×16 权重，也能判断旧三轮 `L_match + L_value` 训练逻辑在细网格上是否保留优势。
