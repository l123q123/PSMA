# PASM v0.2 双图质量采样设计

## 1. 版本目标

v0.2 在不改变 PASM 的核心立场前提下，加入可学习的双图局部质量：

> Patch 只负责预算与语义；匹配、保留和淘汰始终发生在点级。模型不先固定检测一组特征点，而是在全图密集质量场上反复采样。

本版本要回答的问题是：能否用 MegaDepth 的几何和冻结 LoMa 构造软教师，让模型根据图像对本身预测“本 Patch 内哪里更值得采样”，并用这个预测分布驱动三轮点级重采样。

## 2. 已验证的出发点

已在 10 个 MegaDepth 正图像对上比较了均匀随机点与几何-描述子软教师点。每图均为 1024 点，结果均值如下：

| 指标 | 随机点 | 软教师点 |
| --- | ---: | ---: |
| 3px 双向投影覆盖率 | 9.8% | 27.5% |
| 6px 双向投影覆盖率 | 34.6% | 56.5% |
| 3px LoMa mutual 内点率 | 10.8% | 43.5% |
| 6px LoMa mutual 内点率 | 29.8% | 64.3% |

这只说明软教师与“可匹配的局部位置”具有明显相关性，不代表已经得到可部署的质量模型。教师生成使用深度和位姿；v0.2 推理时不使用任何几何真值。

## 3. 固定尺度与术语

- 输入图像：`518×518`。
- 管理 Patch：`16×16`，每块约 `32.4×32.4 px`。
- 局部质量格：每 Patch `8×8`，相邻格中心约 `4 px`，整图为 `128×128=16384` 个质量位置。
- 实际采样点：连续浮点坐标，不限于质量格中心。
- 总预算：每图每轮 1024 点；第 0 轮每 Patch 固定 4 点；后续最低预算、Patch 上限和三轮数沿用 v0.1 配置。

这里的 `128×128` 是足够密的质量场，不采用原始 `518×518` 的逐像素教师。逐像素会使“每个位置与所有错误位置比较”的开销大幅增加，但并不会改变本版本的采样机制。

## 4. 整体结构

```text
冻结 DINO Patch token ──→ 双图 Patch 语义编码器 ──→ Patch 价值
                                      │
冻结 LoMa 稠密特征 ─→ 局部投影 + 对另一图全部 Patch 语义的 Cross-Attention
                                      │
                         联合局部描述子 z 与密集质量 logits q
                                      │
            Patch 内 softmax 采样 → 全局点级匹配 → 锚点与 Patch 预算
```

LoMa 在 v0.2 中仍冻结，只作为可靠的局部输入。新增的投影、局部到另一图语义的 Cross-Attention、联合描述子头和质量头均可训练。因此，本版本不是最终“完全自有描述子”，而是从单图 LoMa 描述子过渡到可训练的双图条件化描述子。

## 5. Patch 语义编码器

### 5.1 输入与输出

输入仍为冻结 DINOv2 产生的两组 `16×16` Patch token。输出为：

- `S_A[256, D]`、`S_B[256, D]`：双图条件化 Patch 语义；
- `V_A[256]`、`V_B[256]`：Patch 价值，用于原有预算分配。

### 5.2 最小结构升级

将 v0.1 的一层共享 Cross-Attention 改为三个顺序模块：

1. 每张图各做一次共享参数的 Self-Attention，先整合本图 256 个 Patch 的上下文；
2. A 查询 B、B 查询 A 的共享双向 Cross-Attention；
3. 再执行一次同结构的共享双向 Cross-Attention。

每个模块均使用残差连接和 LayerNorm。维度、注意力头数维持 v0.1 的小规模设置，避免为了层数堆叠大网络。

## 6. 双图局部编码器

### 6.1 为什么不做稠密 LoMa 对 LoMa 全局 Cross-Attention

两图各有 16384 个局部质量位置，直接让所有 A 局部 token 注意所有 B 局部 token 会形成约 `16384×16384` 的注意力矩阵，代价和显存都不适合 v0.2。

### 6.2 局部查询、另一图 Patch 语义键值

对 A 图每个质量位置 `p`：

1. 从冻结 LoMa 稠密图读取 `l_A(p)`；
2. 通过可训练线性层映射到统一维度，并加上本 Patch 的语义 `S_A[patch(p)]`；
3. 将该局部 token 作为 Query，对 B 图的全部 256 个语义 token `S_B` 做 Cross-Attention；
4. 将注意力结果与本地 token 融合，得到联合局部描述子 `z_A(p)`；
5. 对 B 图执行完全对称的过程，得到 `z_B(p)`。

这使一个局部位置可利用另一张图的整体 Patch 语义，但不构造 Patch 对，也不预先缩小到某几个目标区域。局部 token 始终能看见另一图全部 256 个 Patch。

`z_A`、`z_B` 经过 L2 归一化后替换 v0.1 中的原始 LoMa 点描述子，继续送入已有的全局点级 dual-softmax 匹配。原有 Patch 语义项也保留在边权中。

## 7. 密集局部质量头

### 7.1 输出

质量头对每个联合局部描述子输出一个标量 logit：

```text
q_A(p) = QualityHead(z_A(p))
q_B(p) = QualityHead(z_B(p))
```

于是每图得到一个 `128×128` 的质量 logit 图。它是 `q_A(p | A,B)` 与 `q_B(p | A,B)`：虽然输出在点级，但已条件化于另一张图。

质量头只是一层小 MLP 或线性头，不额外加入可学习的状态、候选池或循环控制器。

### 7.2 离线软教师缓存

对于每个有深度、内参和位姿的 MegaDepth 正图像对，离线生成：

```text
T_A[128,128], T_B[128,128] ∈ [0, 1]
```

每个位置的标签为：

```text
T(p) = visible(p)
     × sigmoid((LoMa(p) 与真实投影的相似度
                - 最强错误位置相似度) / 0.1)
```

不可见、被遮挡、深度无效或投影出界的位置标签为 0。最强错误位置在另一图全部 4px 质量格中寻找，但排除真实投影附近 6px 的位置。

缓存只保存教师图和必要的元数据，不保存教师最终 Top-K 点；因为训练目标是全图质量场，而不是固定特征点列表。

### 7.3 质量损失

令 `sigmoid(q)` 为模型质量概率，使用两张图全部 16384 个位置的软二元交叉熵：

```text
L_quality = mean(BCEWithLogits(q_A, T_A))
          + mean(BCEWithLogits(q_B, T_B))
```

这个损失直接反传到质量头、局部投影、局部 Cross-Attention 和 Patch 语义编码器；不会更新冻结 DINO 和冻结 LoMa。

v0.2 不加入额外的 Top-K 损失、NMS 损失、局部偏移损失或手工排序损失。若训练日志显示质量图坍塌，再单独讨论是否需要 Patch 内排序目标，而不是预先堆叠损失。

## 8. 采样与三轮演化

### 8.1 核心原则

质量图定义的是概率分布，不是固定检测到的关键点集合：

- 从不先取质量 Top-K 形成候选池；
- 从不在上一轮未锚定点中筛选下一轮点；
- 每次非锚点采样都回到该 Patch 的全部 `8×8` 质量格；
- 质量格只是数值积分和抽样载体，最终点坐标仍是连续的。

### 8.2 Patch 内概率分布

对 Patch `k` 内的 64 个质量位置，计算：

```text
π_k(i) = softmax(q_k(i))
```

softmax 不引入额外温度参数，初始直接使用质量 logits。质量图全低时，分布自然接近均匀；质量图在某些结构位置高时，采样自然向这些位置集中。

### 8.3 同一轮：无放回；不同轮：可重复

若 Patch 本轮预算为 `b_k`，其中已有 `a_k` 个锚点，则剩余 `m_k=b_k-a_k` 个非锚点按 `π_k` 做加权无放回采样：

```text
cells = multinomial(π_k, m_k, replacement=False)
```

每个被选中的 4px 格内部均匀生成一个连续浮点坐标。因此：

- 同一轮同一 Patch 内不会抽两次同一个质量格；
- 下一轮会重新使用完整的 64 格分布，可以再次抽到上一轮同一格；
- 锚点的精确坐标已经占用一个点预算，非锚点坐标不复制它；不屏蔽锚点邻域，也不人为在锚点附近加权。

如果下一轮再次抽中包含锚点的质量格，只会在该格内得到另一个连续坐标。这不是锚点邻域规则，而是质量场本身在该位置保持高概率的自然结果。

### 8.4 第 0 轮

第 0 轮没有锚点，所有 Patch 固定预算 4。因此每个 Patch 直接从自己的 `π_k` 无放回抽取 4 个质量格，并在格内取连续坐标。全图仍严格为 1024 点。

### 8.5 轮间保留与预算

以下规则完整沿用 v0.1：

1. 对当前 1024×1024 点边权做全局互相最佳匹配；
2. 高置信边按现有阈值、两侧 Patch 上限和总预算约束选择锚点；
3. 锚点两端坐标原样进入下一轮，并占用所属 Patch 预算；
4. Patch 预算仍由 `Patch 价值 + 当前点级边反馈 + 锚点支持` 分配；
5. 第 1 次重采样保留每 Patch 至少 1 点，第 2 次重采样允许低价值 Patch 为 0 点，每 Patch 上限仍为 20。

质量图在 v0.2 内不直接增加 Patch 预算，也不根据某条边临时改变 Patch 内分布。它只定义“已获得的 Patch 内预算应往哪里采”。这样 Patch 间演化与 Patch 内采样职责清晰分离。

### 8.6 三轮状态

质量图 `q_A、q_B` 对同一图像对只计算一次；它不依赖上一轮随机点，因此在三轮中保持不变。跨轮变化仅来自：

```text
锚点被保留
+ Patch 获得或失去预算
+ 对同一质量分布进行新的随机无放回抽样
```

这不是连续坐标梯度下降，也不是固定检测点筛选。它是一个静态双图质量先验与动态点级匹配筛选共同形成的随机重采样过程。

## 9. 匹配、训练与梯度

### 9.1 点级匹配

每一轮在实际采样到的连续坐标处双线性读取联合描述子 `z_A、z_B`，随后保持 v0.1 的全局点级匹配：

```text
局部 z 描述子相似度 + 所属 Patch 语义相似度
→ dual-softmax 边权
→ 互相最佳边、锚点与最终匹配
```

仍没有 Patch 对，也没有“每个粗匹配只产生一个精匹配”的限制。

### 9.2 训练损失

每轮仍用直接几何投影产生当前采样点的正对应，并用固定投影网格产生 Patch 价值目标。v0.1 的每轮损失不变：

```text
L_round^r = L_match^r + L_value^r
L_base = (L_round^1 + L_round^2 + L_round^3) / 3
```

新增质量监督后的总损失为：

```text
L_total = L_base + L_quality
```

`L_match` 的梯度训练联合局部描述子和 Patch 语义；`L_value` 训练 Patch 价值；`L_quality` 密集训练质量图。采样的 `multinomial` 本身不需要可微：质量头由覆盖全图的 `L_quality` 直接训练，而不是等待随机采样点恰好被选中才得到梯度。

### 9.3 训练与推理的几何边界

训练：深度、内参和位姿只用于生成 `L_match` 标签、`L_value` 目标和离线 `T_A/T_B` 教师图。

推理：输入仅为 A、B 图像和模型权重；质量图、采样、匹配、锚点和预算均由预测结果完成，不读取深度或位姿。

## 10. 训练数据与缓存流程

1. 只对有完整深度和相机信息的 MegaDepth 正图像对生成质量教师缓存；
2. 每条缓存保存 A、B 两张 `128×128` 浮点教师图、图像缩放参数和版本标记；
3. 训练时读取 RGB、DINO token、LoMa 特征与对应教师图；
4. 每对图在三轮中预测一次质量图、按该质量图采样三轮点集，并计算 `L_total`；
5. 校验集必须和训练图像对分离；优先从同一场景的未训练图像中构造测试对，以验证不是记住训练对。

离线缓存计算较慢，但一次生成后可重复使用，避免每个训练 epoch 重复执行深度投影和最强错误描述子搜索。

## 11. v0.2 必做验证

### 11.1 质量头是否学到教师

- 预测质量图和教师图的散点关系、平均 BCE；
- 每 Patch 中预测分数最高的 4 个位置，其教师分数是否高于随机 4 点；
- 在未训练图像对上输出质量图与采样点图，检查是否仍集中于稳定结构而非只记住训练图。

### 11.2 采样闭环是否改善

与 v0.1 均匀初始化/旧重采样比较，按轮记录：

- 3px、6px 双向投影覆盖率；
- mutual matching 数量及 3px、6px 几何内点率；
- 每轮锚点数量和跨轮精确保留率；
- 每 Patch 预算分布及被淘汰 Patch 数量；
- 同一 Patch 跨轮重复抽中质量格的比例，但不把它当作错误。

### 11.3 最小消融

只做两个必要对照：

1. `冻结 LoMa + v0.1`：当前基线；
2. `v0.2 质量图采样`：验证密集质量监督和新采样是否有价值；
3. `v0.2 联合局部描述子 + 质量图采样`：验证局部 Cross-Attention 是否额外改善匹配。

不在 v0.2 阶段加入 RANSAC 位姿评测、拒绝机制、负场景分类、连续偏移或更多采样规则。

## 12. 明确不做的事

- 不创建固定 Top-K 特征点池；
- 不构造 Patch 对或粗到细候选链；
- 不在锚点附近追加手工高斯采样；
- 不维护候选点历史状态；
- 不对每个原始像素生成教师；
- 不训练 LoMa 主干，不立即完全替换 LoMa；
- 不加入 RANSAC、相对位姿损失、dustbin、拒绝头或场景负例；
- 不把训练几何真值带入推理。

## 13. 完成判据

v0.2 的第一阶段成功，不以立即超过 LoMa 为判据，而要求同时满足：

1. 质量头在未训练正图像对上仍能输出视觉合理的密集高质量区域；
2. 质量采样相对 v0.1 提高几何覆盖率或匹配内点率，且不依赖推理真值；
3. 三轮过程中锚点可稳定保留，非锚点点集能跨轮重新抽样；
4. 结果显示采样不是固定单图检测点，而是随输入图像对改变的双图条件化分布。
