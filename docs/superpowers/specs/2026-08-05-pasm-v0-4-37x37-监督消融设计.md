# PASM v0.4：37×37 Patch 监督真值 A/B 消融设计

## 目标

在 DINOv2 原始 `37×37` token 尺度上，将 PASM 收缩为单轮静态流程，并用严格控制变量实验决定 Patch 价值头应学习哪一种真值：几何共同可见性，或 LoMa 局部质量教师。

## 固定流程

对每一对 `518×518` 图像：

1. 冻结 DINOv2 输出 `37×37` token；PASM 双图语义编码器输出两图各 `1369` 个 Patch 价值。
2. 根据价值头输出，为每图恰好 `1024` 个点分配 Patch 预算；每个 Patch 的预算范围为 `0～4`，预算指数固定为 `1.0`。
3. 冻结 DaD 在每个 Patch 的预算内选择局部特征点。
4. 冻结完整 LoMa-B128 描述并匹配两图各 `1024` 个点。

本版本不保留三轮采样、锚点、跨轮反馈、重采样、质量头、相对位姿损失或新匹配器。

## A/B 对照

两组训练必须使用相同的：随机种子、96 个 MegaDepth 正图像对、网络初始化、优化器、学习率、训练轮数、DaD、LoMa、点级几何匹配损失和 held-out 评测图像对。唯一变化是 `L_value` 的 Patch 目标。

| 组别 | 名称 | `L_value` 目标 |
| --- | --- | --- |
| A | `geometry` | 以 `stride=2` 规则像素格执行双向深度可见性投影，将每图可见点数按 37×37 Patch 汇总后归一化。 |
| B | `quality` | 以 `stride=2` 规则像素格先通过几何可见性，再用 LoMa 的真实投影正描述子相似度与排除真实投影邻域后的 hardest negative 相似度差构造软质量，按 37×37 Patch 均值汇总后归一化。 |

两组损失均为：

```text
L_total = L_match + L_value
```

其中 `L_match` 使用当前由 DaD 静态选出的点，以深度和位姿直接投影，在对方点集中寻找 `6px` 内的双向最近点，并对有效行的可微匹配边权计算交叉熵。训练边权由冻结 LoMa 稠密描述子的局部相似度与可训练双图语义相似度组成；训练时不调用完整 LoMa Transformer 匹配器，因为其指定点匹配接口、Patch 预算和 DaD 选点均是离散或冻结操作，不能向 PASM 反传梯度。`L_value` 是价值头输出归一化分布与上述 A 或 B 目标分布的交叉熵。

## 离线目标缓存

每个正图像对生成一个 `.npz`，包含：

- `target_a`、`target_b`：长度 `1369`、非负且和为一的 Patch 目标；
- `target_kind`：`geometry` 或 `quality`；
- `patch_rows`、`patch_cols`、`image_size`、`stride`；
- `pair_id`。

缓存只保存 37×37 聚合后的真值，不保存密集 LoMa 描述子或 259×259 中间网格。质量缓存离线生成时使用约 `259×259=67081` 个采样位置，开销只发生一次。

## 配置与兼容边界

新增 `dino_token_static_config()`，固定返回：

```text
image_size=518
patch_rows=37
patch_cols=37
total_points=1024
iterations=1
round_min_points=(0,)
max_points_per_patch=4
budget_score_power=1.0
geometry_support_stride=2
```

现有 `PasmV0Config()`、v0.1/v0.2/v0.3 训练、推理与检查点加载逻辑不改变。v0.4 使用独立命令入口和独立输出目录，避免对旧 checkpoint 的 16×16 配置作隐式覆盖。

## 训练与评测

先对 A、B 各训练 1 轮，验证目标缓存、可微匹配损失和 checkpoint；随后各训练 20 轮进行方向选择。若两组指标接近或仍在明显收敛，则从各自 checkpoint 续训至 60 轮。

在同一 9 组 held-out MegaDepth 图像对上统计：

- 互为最近邻匹配总数；
- 3px、6px 内点数与内点率；
- 高置信匹配的数量与内点率；
- 双向几何覆盖率；
- Patch 预算与 `stride=2` 几何共同可见性的一致性；
- 活跃 Patch 数量、预算熵和每 Patch 预算上限命中数。

每个图像对保存 A/B 各自的预算热图、选点图、全部匹配图和高置信匹配图。选择监督时优先比较绝对 3px/6px 内点数与重投影质量；内点率提升但绝对内点数明显下降不算胜出。

## 验收标准

1. A/B 训练只能通过明确的 `--target-kind geometry|quality` 改变 `L_value` 的监督，不得改变任何其他训练超参数。
2. 缓存的目标形状固定为 `[1369]`，有限、非负，且每图和为一；无可见支持的样本必须在生成时明确报错而非静默产生全零目标。
3. v0.4 推理每图始终输出 `1024` 个不重复、边界内的 DaD 点，且实际 Patch 点数等于静态预算。
4. A/B 汇总报告必须在相同 held-out 图像对上写出同一套几何与预算统计字段。
5. 现有 v0.3 测试与新增 v0.4 的配置、缓存、训练目标选择测试均通过。
