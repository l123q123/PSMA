# PASM v0.3：留出几何评测与 Patch 热图设计

## 目标

为 v0.3 的两个单轮模式建立可重复的多组几何评测，并直接观察 PASM 的静态 Patch 预算是否集中到两图共同可见的区域：

- `dad_global`：全图 DaD 选 1024 点，完整 LoMa-B128 匹配；
- `pasm_dad`：PASM 双图静态 Patch 预算、Patch 内 DaD 选 1024 点，完整 LoMa-B128 匹配。

本工具只做推理、统计和可视化；不使用深度或位姿参与选点、预算或匹配。

## 严格留出图像对

评测集固定使用 MegaDepth mini 场景 `0285/0` 中未出现在训练正图像对任一侧的图像。脚本读取训练清单后，必须验证每个评测图像的规范路径均不在训练正对的图像集合内；一旦有重叠立即报错。这样得到的是“同场景、未见图像”评测，而不是跨场景泛化评测。

## Patch 几何真值

对每张图，在固定的 518×518 模型坐标系中建立规则投影网格。每个网格点按深度、内参和相机位姿投影到另一图，并用目标深度进行可见性检查。

某个源 Patch 的几何支持为：该 Patch 内通过双图可见性检查的网格点数量；所有 256 个 Patch 的支持再归一化为和为 1 的分布。该分布称为 `geometry_support`。

它代表“本图中哪些区域在当前图像对里有更多共同可见面积”，而不是角点质量、描述子可区分性或相机位姿价值的完整人工真值。它适合检验 PASM 的联合区域预算是否朝共同可见区域聚集，但不能单独证明 Patch 内局部点是否更好。

## 每组输出

每个图像对建立独立目录，分别保存两种方法的 `result.npz`、点图、全部匹配图和高置信匹配图；并额外保存：

- `budget_heatmap_a.png`、`budget_heatmap_b.png`：`pasm_dad` 的 16×16 实际整数点预算；
- `geometry_support_heatmap_a.png`、`geometry_support_heatmap_b.png`：对应图的共同可见几何支持；
- `patch_values.npz`：预算、几何支持及相关性所需原始数组。

热图不叠加原图，采用蓝—白—红颜色表示低—中—高；同一张图的预算与几何支持分别按自身数值范围线性映射颜色，同时在文件中保留原始数组，以免可视化缩放掩盖数值差异。

## 几何指标

对每个 `method × pair` 输出：

- `mutual_matches`：完整 LoMa 的互为最强匹配数；
- `inliers_3px`、`inliers_6px`：A→B 真实投影误差不超过 3/6 像素且通过可见性检查的匹配边数量；
- `inlier_rate_3px`、`inlier_rate_6px`：上述内点数除以全部互为最强匹配数；
- `coverage_3px`、`coverage_6px`：A→B 与 B→A 选点投影覆盖率的平均值；
- `high_confidence_matches`、`high_confidence_inliers_3px/6px`、对应内点率：仅取 LoMa 置信度不低于 0.6 的边。

根目录的 `summary.csv` 按图像对、模式列出原始指标；`aggregate.csv` 另给出两种模式的逐对宏平均和全部匹配边的全局内点率。只比较同一图像对内的两种模式，不将“匹配条数更多”直接解释为更好。

## 预算与几何支持一致性

对 `pasm_dad` 的 A/B 图分别计算：

- Patch 预算与 `geometry_support` 的 Spearman 等级相关系数；
- 预算最高的 26 个 Patch 与几何支持最高的 26 个 Patch 的重合率。

这两个指标仅衡量“PASM 区域预算是否指向共同可见区域”。即使相关性提高，也仍需结合 DaD 点分布和 LoMa 几何内点率判断整体是否受益。

## 实现边界

- 新增独立命令 `pasm_v0.evaluate_v03`，复用冻结 DaD、完整 LoMa、PASM 检查点和现有几何函数；模型在一次评测启动后只加载一次。
- 新增一个只包含相对图像文件名的固定留出对 JSON；运行时由 `--image-root` 定位实际数据目录。
- 不修改训练、v0.2 三轮路径、`dad_global` 或 `pasm_dad` 的选点/匹配决策。
- 默认固定 9 组、3px/6px、0.6 高置信阈值、8 像素几何支持网格；命令行可下调 `--max-pairs` 用于快速验证。
