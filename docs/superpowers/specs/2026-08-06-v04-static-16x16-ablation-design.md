# v0.4 静态 16×16 Patch 对照实验设计

## 目标

验证 v0.4 单轮静态训练效果不佳的主因，究竟是 37×37 Patch 过密，还是 v0.4 的训练方式本身。实验只改变 Patch 网格密度。

## 对照定义

新的 16×16 实验与现有 37×37 v0.4 单层模型保持以下部分完全一致：

- 图像输入为 518×518，DINOv2、DaD、LoMa 全部冻结。
- 单轮静态流程：双图语义编码器输出 Patch 价值，预算分配后由 DaD 在每个 Patch 内选点，再由冻结 LoMa matcher 匹配。
- 一层双向 Cross-Attention，`hidden_dim=128`，`heads=4`。
- `value_only`：仅几何 Patch 价值损失参与反向传播。
- 总预算 1024 点，37×37 Patch 单块上限 4；16×16 Patch 单块上限 20，`budget_score_power=1.0`。
- 几何教师仍由 MegaDepth 深度、内外参与相机位姿投影生成，规则支持点间隔为 2 像素。
- 训练清单和九组 held-out 评测图像完全沿用现有 v0.4 实验。

唯一变化为 `patch_rows=patch_cols=16`，即整图被划为 256 个约 32×32 像素的 Patch，而不是 1369 个约 14×14 像素的 Patch。

## 方案比较

1. **推荐：单层 v0.4，严格只改 37×37 到 16×16。** 可直接回答“Patch 过密是否损害静态预算学习”。
2. 两层 v0.4 改为 16×16。会把网络容量和网格尺度混在一起，不能定位原因。
3. 复用旧三轮训练改为 16×16。会把采样机制和训练损失混入对照，不能回答当前问题。

本实验采用方案 1。

## 最小实现

- 为 v0.4 静态配置提供 `16` 或 `37` 的网格选择，默认保持 37；16×16 使用上限 20，避免 256 个 Patch × 4 点恰好耗尽全部预算而失去价值分配作用。
- `cache_v04_targets` 支持 `--patch-grid 16`，单独生成 `geometry` 的 16×16、stride=2 缓存；37×37 缓存不能复用，因为监督向量长度与 Patch 边界均不同。
- `train_v04` 支持 `--patch-grid 16`，训练时把该配置写入 checkpoint。
- `evaluate_v04` 支持 `--patch-grid 16`，同时验证两个 checkpoint 的网格配置与所选网格一致。
- 推理继续从 checkpoint 读取配置，因此无需增加推理参数。

## 成功判据

以同一批九组 held-out 图像比较单层 16×16 与单层 37×37：

- 首要：3px/6px 内点数、内点率与覆盖率。
- 辅助：预算与几何支持的 Spearman、Top-26 Patch IoU、活跃 Patch 数和预算熵。
- 若 16×16 在绝对内点数与覆盖率上明显改善，则 37×37 的过密网格是主要因素；若两者都差，则先怀疑 v0.4 的价值监督训练方式，而不继续增加层数。

## 非目标

- 不增加 Cross-Attention 层数或自注意力。
- 不修改 DaD 选点、LoMa matcher、损失函数或预算分配规则。
- 不重新引入三轮采样。
