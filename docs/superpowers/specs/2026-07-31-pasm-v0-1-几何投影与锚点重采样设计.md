# PASM v0.1 几何投影与锚点重采样设计

## 1. 目标

v0.1 只优化两个问题：

1. 不再让当前采样点去寻找稀疏几何缓存点，而是使用深度、内参和相机位姿，把当前点直接投影到另一张图，再寻找当前采样点中的最近邻作为监督目标。
2. 对高置信、互相最佳的点级匹配进行原样保留，并让 Patch 预算同时受到锚点支持、Patch 价值和匹配反馈的影响。

v0.1 仍然使用冻结的 DINOv2 和 LoMa 描述子，仍然使用全局点级匹配，不建立 Patch 对，也不加入完整的 LoMa 式可训练匹配器。

## 2. 当前 v0 的问题

当前点级标签流程是：当前 A 点先寻找几何缓存中的最近点，再把该缓存点对应的 B 坐标与当前 B 点比较。这会使监督质量依赖几何缓存的密度。

当前重采样流程只在旧高质量点附近生成扰动点，不保留旧点的原始坐标。因此，某一轮已经得到的高置信匹配可能在下一轮消失。

## 3. 数据读取

现有 MegaDepth 清单已经提供以下字段：

- `depth_A`、`depth_B`：两张图的 EXR 深度图；
- `camera_A`、`camera_B`：包含 `cam2world` 和 `intrinsics` 的 Safetensors 相机文件；
- `label`：图像对是否为几何正对。

`PairRecord` 需要增加深度路径和相机路径。正图像对读取完整几何信息；负图像对不产生正几何标签。旧的 `geometry_cache` 字段暂时保留，以兼容已有清单和可视化脚本，但不再参与点级正样本生成。

## 4. 直接投影的点级标签

### 4.1 坐标处理

RGB 图像会被直接缩放到 `518×518`。因此，投影模块统一在模型输入坐标系中工作：

- 当前采样点先按原图尺寸映射到深度图坐标，读取源点深度；
- 原始内参按输入图像的横向、纵向缩放比例分别缩放；
- 投影结果直接得到 `518×518` 坐标，便于和当前采样点计算像素距离。

### 4.2 A→B 投影

对于当前 A 图点 `p_A`：

1. 读取 `p_A` 对应的有效深度 `z_A`；
2. 使用 A 图内参反投影到 A 相机坐标系；
3. 使用 `inv(cam2world_B) @ cam2world_A` 变换到 B 相机坐标系；
4. 使用 B 图内参投影为连续像素坐标 `q_B`；
5. 丢弃深度无效、位于相机后方或落在 B 图范围外的点；
6. 在当前 B 图采样点中寻找距离 `q_B` 最近的点；
7. 最近距离小于 `3px` 时，得到一个 A→B 候选正对应。

### 4.3 双向一致性和可见性

B→A 执行完全相同的过程。只有同时满足以下条件的点对才作为最终正样本：

- A→B 和 B→A 都通过有效深度与图像范围检查；
- A→B 选择 B 点，B→A 也选择同一个 A 点；
- 两个方向的最近邻距离都不超过 `3px`；
- 投影深度与目标图实际深度通过相对误差检查，初始阈值为 `1%`。

这样得到的正样本来自“当前采样点和真实投影位置之间的距离”，不需要当前两个点先去凑一个缓存几何点。

如果源点深度无效、目标点被遮挡、投影点出界或点对不满足双向最近邻，则该源点不产生点级正监督。

## 5. Patch 价值目标

为了让 Patch 价值监督也不依赖缓存点，使用固定稀疏网格生成 Patch 支持目标：

1. 在 A 图输入坐标上按 `4px` 步长生成规则网格；
2. 对网格点执行 A→B 投影和目标深度一致性检查；
3. 将有效投影的源网格点按所属 A Patch 计数并归一化；
4. 对 B 图执行 B→A，得到 B Patch 的支持分布。

该固定网格只用于生成 Patch 价值监督，不作为模型运行时的候选点集合，也不改变全局点级匹配范围。

因此，Patch 价值的含义变为：该 Patch 中有多少具有有效几何可见对应的图像区域，而不是缓存里恰好有多少个点。

## 6. 高置信匹配锚点

每轮计算完整点对边权后，使用全局互相最佳匹配得到候选边。候选边需要满足：

- A 点和 B 点互相选择对方为最佳匹配；
- 边权超过锚点阈值；
- 两端 Patch 尚未达到每块最大点数。

候选边按边权从高到低贪心选择，保证一条被保留的边两端同时成为锚点。锚点来自模型预测，不使用训练几何真值直接干预采样，以保持训练和推理流程一致。

锚点只表示“下一轮采样时保留的高置信点对”，不直接保证它们一定出现在最终输出匹配中；最终匹配仍由最后一轮的全局边权和互相最佳规则决定。

## 7. Patch 预算分配

对每张图分别统计：

- 模型预测的 Patch 价值；
- 当前点级边质量反馈；
- 该 Patch 中已保留锚点的数量。

预算分配遵循以下规则：

1. Patch 的最低预算至少覆盖本轮规定的最低点数；
2. Patch 的最低预算还必须覆盖该 Patch 的锚点数量；
3. 剩余预算按 `Patch 价值 + 匹配反馈 + 锚点支持` 分配；
4. 每个 Patch 不超过最大点数；
5. 所有 Patch 的预算总和保持为总采样预算。

如果锚点候选多于 Patch 上限，则优先保留边权最高的锚点。A、B 两侧的预算共同受到同一批锚点边的约束，避免只保留匹配边的一端。

## 8. 保留式 Patch 内重采样

给定 Patch 的下一轮预算 `n` 和锚点数量 `k`：

1. 原样放入 `k` 个锚点；
2. 从剩余 `n-k` 个名额中按探索比例生成均匀探索点；
3. 其余名额以锚点为中心，在当前 Patch 内进行局部扰动采样；
4. 所有局部扰动点都裁剪到当前 Patch 边界内。

初始探索比例沿用 v0 的 `25%`。如果 Patch 没有锚点，则使用该 Patch 内旧点的边质量作为局部采样权重；如果该 Patch 也没有旧点，则剩余点全部均匀探索。

因此每一轮的点集同时包含三类点：

```text
已确认的高置信锚点
+ 锚点附近的局部探索点
+ Patch 内的均匀探索点
```

## 9. 训练和推理流程

训练时：

```text
读取 RGB、深度、内参和位姿
→ 初始化每个 Patch 的首轮点
→ 计算 LoMa 描述子、联合语义和全局边权
→ 用直接投影生成当前点级正样本
→ 用投影网格生成 Patch 价值目标
→ 根据预测高置信边保留锚点并重采样
→ 重复后续轮次
→ 对所有轮次计算损失并更新 PairSemanticEncoder
```

推理时：

```text
读取 RGB 并提取冻结特征
→ 初始化点
→ 全局计算边权
→ 仅使用模型预测的高置信互相匹配作为锚点
→ 保留锚点并重采样
→ 最后一轮输出互相最佳匹配
```

推理不使用深度真值来决定锚点；深度和位姿只在训练标签与离线评估中使用。

## 10. 预期验证指标

v0.1 实验重点不是立即超过 LoMa，而是验证采样机制：

- 每轮 Patch 预算标准差和最大/最小预算差距增大；
- 高支持 Patch 获得更多预算；
- 高置信锚点的跨轮保留率接近 `100%`；
- 锚点附近新增点的几何正样本率高于均匀探索点；
- 正样本率、内点率和有效匹配数量随轮次不下降；
- 与不保留锚点的 v0 对照时，点移动更稳定、匹配质量更高。

实验中同时记录正样本总数和正样本率，避免因为总采样点增加而误把数量增长当成质量提升。

## 11. 暂不处理的内容

- 不训练新的点级匹配 Transformer；
- 不替换 LoMa 描述子；
- 不加入 dustbin 和显式 matchability 头；
- 不做连续坐标梯度移动；
- 不做 Patch 对筛选；
- 不使用训练真值直接强行保留采样点。

这些内容留到确认 v0.1 采样闭环有效后再单独迭代。
