# PASM v0.5 残差式稠密点融合设计

日期：2026-08-06  
状态：设计已获用户确认，待实现

## 1. 背景与目标

当前 PASM 的两阶段流程是先由 DINO Patch 语义值分配预算，再在激活 Patch 内调用冻结 DaD 选点。Patch 级预算能够表达双图可见性区域，但会限制 DaD 的像素级点选择；37×37 细网格下这种限制尤其明显。

本方案取消 Patch 级硬预算，改为直接预测像素级点响应图：

- 冻结 DaD 提供单图、点级的重复性和局部稳定性先验；
- 已训练的双图语义编码器提供双图可见性和区域级几何先验；
- 轻量融合头对 DaD 响应做残差修正；
- 仍使用 NMS 和全局 Top-K，最终每张图选择 1024 个点；
- 推理阶段不使用深度、位姿或其他几何真值，后续 LoMa 匹配流程保持不变。

## 2. 范围与非目标

### 范围

1. 在现有 v0.4 语义编码器基础上增加点级融合头。
2. 暴露冻结 DaD 的 32 通道稠密特征和原始检测 logits。
3. 使用训练图像对的深度、相机内参和位姿生成候选点级软教师。
4. 使用同一融合头比较 16×16 和 37×37 语义网格。
5. 使用现有 LoMa 推理和留出九组几何评测指标进行验证。

### 非目标

- 不重新训练 DaD。
- 不在推理阶段使用深度或位姿。
- 不修改 LoMa Transformer、DeDoDe 描述子或匹配过滤规则。
- 不引入 Patch 激活、Patch 上限或 Patch 预算分配。
- 第一版不实现像素到 Patch 的全量 cross-attention。

## 3. 模型架构

### 3.1 DaD 分支

对每张图单独运行冻结 DaD，得到：

- `F_dad ∈ R^{C×H_d×W_d}`：DaD 最终检测头之前的 32 通道稠密特征；
- `R_dad ∈ R^{K×H_d×W_d}`：DaD 网络原始多通道检测 logits；
- `P_dad ∈ R^{1×H_d×W_d}`：对 `R_dad` 做空间/通道归一化并聚合后的稠密检测概率；
- `B_dad`：由 `P_dad` 转换得到的单通道基础 logit，可作为融合输入和残差基线。

DaD 的输入预处理、宽高比处理和坐标映射沿用现有实现。需要提供稳定的 `return_features` 接口，避免通过非稳定的外部 hook 依赖内部层名。

### 3.2 双图语义分支

使用现有 DINO 特征和已训练双图语义编码器。对于 A、B 两图，取 cross-attention 后、最终 scalar value head 之前的 token hidden：

```text
H_A: [B, N_patch, D]
H_B: [B, N_patch, D]
```

不能只使用最终 Patch scalar value，因为 scalar 已经丢失过多通道信息。`H_A` 和 `H_B` 使用同一个语义编码器和同一组权重，保留双图交互信息。

### 3.3 空间对齐与融合头

将语义 token reshape 成 `patch_rows × patch_cols`，通过共享线性投影变换到 32 通道，再双线性上采样到 DaD 特征图分辨率：

```text
H_A → Linear(D→32) → reshape → bilinear upsample → H_up_A
H_B → Linear(D→32) → reshape → bilinear upsample → H_up_B
```

A、B 两图使用同一个 Fusion Head：

```text
ΔB = FusionHead(concat(F_dad, H_up, B_dad))
B_final = B_dad + α · ΔB
```

Fusion Head 第一版使用 `3×3 Conv → Norm → GELU → 3×3 Conv → 1×1 Conv`。`α` 是可学习标量，初始化为 0，使训练初始状态严格退化为 DaD 基线。这样语义分支只学习对 DaD 的相对修正，不会直接替代 DaD 的局部检测能力。

## 4. 点级几何教师

### 4.1 候选池

训练时从冻结 DaD 稠密响应图中生成大候选池 `C_A`、`C_B`，候选数量大于最终预算。第一版默认使用 4096 个候选点，必要时再评估 8192 个候选点。候选池使用 DaD 的 NMS 和亚像素流程，但不使用最终 1024 点截断。

### 4.2 A→B 标签

对 A 中每个候选点 `p_A`：

1. 从 A 点读取深度并反投影到三维；
2. 使用相机位姿变换到 B 相机坐标系；
3. 投影到 B 图像平面；
4. 执行图像边界、正深度和 B 深度可见性检查；
5. 在 B 候选池中寻找距离最近的点。

设最近距离为 `d_A`，可见性标志为 `v_A`，则软标签为：

```text
q_A = v_A · exp(-d_A² / (2σ²))
```

不可见、投影越界或没有有效邻近候选点时，`q_A=0`。B→A 使用完全对称的流程生成 `q_B`。距离和可见性计算使用与现有几何评测一致的 518×518 模型坐标系和深度容差。

初始实验参数建议：`σ=3 px`，邻近候选搜索半径 6～12 px；这些参数作为配置项，不写死在模型中。

该教师只在训练阶段使用真值，推理阶段不保留几何依赖。它表达的是“这个 DaD 候选点在另一张图中是否存在可见且位置接近的稳定候选点”，而不是 Patch 级覆盖。

## 5. 训练目标

融合头只在 DaD 候选点位置计算监督，避免将大量背景像素全部当成负样本。

### 5.1 点级损失

对候选点的 `B_final` 与软标签 `q` 使用加权 BCE 或 focal loss：

```text
L_point = BCEWithLogits(B_final(candidate), q)
```

### 5.2 排序损失

最终目标是 Top-1024 排序，因此增加正负候选点的 pairwise ranking loss：

```text
L_rank = max(0, margin - score_positive + score_negative)
```

正负样本按 `q` 分位数采样，避免人为设置过窄的二值阈值。

### 5.3 总损失

```text
L_total = L_point + λ_rank · L_rank
```

第一阶段冻结 DaD、DINO 和语义编码器，只训练投影层与 Fusion Head。若第一阶段有效，再以较小学习率解冻语义编码器最后一层进行可选微调。DaD 始终冻结。

## 6. 推理流程

推理时：

1. A、B 独立运行冻结 DaD，得到稠密特征、聚合概率图和基础 logit；
2. DINO + 双图语义编码器产生 A、B 的 cross-attention token hidden；
3. token 特征上采样并送入共享 Fusion Head；
4. 得到 `B_final_A`、`B_final_B`；
5. 对每张图分别执行 DaD 风格 NMS、亚像素修正和全局 Top-1024；
6. 将两组点交给现有 LoMa matcher；
7. 不读取深度、相机或位姿文件。

## 7. 实验与验收

固定同一批九组留出图像对，至少比较：

21. 原生 DaD/LoMa 全局 048 点；
2. 现有 16×16 Patch 预算模型；
3. 现有 37×37 Patch 预算模型；
4. 16×16 残差稠密融合；
5. 37×37 残差稠密融合。

统一报告：匹配数、3px/6px 内点数、内点率、几何覆盖率、选点空间分布和教师分数 Top-K 均值。

第一版成功标准：

- 不低于冻结 DaD 选点基线的匹配稳定性；
- 相比现有 Patch 预算版本，3px/6px 内点率或覆盖率有明确提升；
- 16×16 与 37×37 使用同一融合头即可运行，不需要 Patch 上限或特殊采样规则。

## 8. 主要风险与处理

1. **教师依赖 DaD 候选池**：使用 4096/8192 大候选池而不是最终 1024 点，降低教师被预算限制的风险。
2. **语义特征过粗**：语义只作为 soft residual，DaD 保留原始像素级分辨率；不使用硬 Patch mask。
3. **候选点距离计算开销大**：实现时使用 KD-tree 或分块最近邻，避免构造完整候选点距离矩阵。
4. **融合头破坏 DaD 原有分布**：残差系数从 0 初始化，并保留 `L_dad` 直连。
5. **训练标签只反映几何接近**：第一版先验证几何重复性假设；若有效，再加入冻结 DeDoDe 相似度作为可选质量项。
