# 软质量教师可视化 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 对 MegaDepth 的前 10 个正图像对比较均匀随机选点与“几何可见且 LoMa 可区分”的软质量教师选点，并保存直观图和少量量化结果。

**Architecture:** 在 `geometry.py` 暴露双图可见投影坐标；新 `quality_teacher.py` 在单图 Patch 内计算教师分数、选择固定四点、并计算点集覆盖和 LoMa 互为最近邻的几何统计；新 CLI 只加载冻结 LoMa，逐对生成独立结果目录和汇总 CSV。它不使用 PASM 检查点，也不改变现有训练、推理和重采样。

**Tech Stack:** Python 3、NumPy、PyTorch、Pillow、冻结 LoMa-B128、MegaDepth 深度/相机几何、`unittest`。

## Global Constraints

- 图像统一缩放到 `518×518`，使用 `16×16` 管理 Patch，每 Patch 始终选择 `4` 点，总计 `1024` 点。
- 处理清单中前 `10` 条具备完整几何信息且标签为正的图像对。
- 教师分数为可见性乘以 `sigmoid((正描述子相似度 - 最强错误相似度) / 温度)`；错误候选须离真实投影超过排除半径。
- 每个代码文件顶部、每个函数的说明均使用一句中文；实现保持简洁。
- 输出仅用于肉眼和快速量化对照；不训练、不加载 DINO/PASM 检查点、不做 RANSAC 或位姿评测。
- 用户要求不创建分支、不提交 Git；目录没有 Git 仓库，因此所有验证均在当前目录执行。

def visible_projected_points(points, geometry, direction, depth_tolerance):

                                       geometry.depth_b, geometry.intrinsics_b, geometry.cam2world_b,

                                       depth_tolerance)
    raise ValueError("投影方向必须为 a_to_b 或 b_to_a")

```python
def patch_candidate_points(layout, candidates_per_axis=8):
    """在每个管理 Patch 内生成均匀局部候选格。"""
    offsets = (np.arange(candidates_per_axis, dtype=np.float32) + 0.5) / candidates_per_axis
    candidates = []
    patch_ids = []
    for patch_id in range(layout.config.patch_count):
        x0, y0, x1, y1 = layout.bounds(patch_id)
        grid_y, grid_x = np.meshgrid(y0 + (y1 - y0) * offsets, x0 + (x1 - x0) * offsets, indexing="ij")
        candidates.append(np.column_stack((grid_x.ravel(), grid_y.ravel())))
        patch_ids.extend([patch_id] * candidates_per_axis**2)
    return np.concatenate(candidates).astype(np.float32), np.asarray(patch_ids, dtype=np.int64)
```
