# PASM v0.2 双图质量采样实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: 使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务执行。步骤使用 `- [ ]` 勾选跟踪。

**目标：** 在不改变 v0.1 的三轮点级匹配和 Patch 预算逻辑前提下，实现双图条件化密集质量图、质量驱动的 Patch 内重采样、离线软质量教师缓存，以及可在本机训练和推理的 v0.2 入口。

**架构：** 每个管理 Patch 维护 `8×8` 局部质量格。冻结 LoMa 描述子经可训练投影和“局部 Query 到另一图全部 Patch 语义”的 Cross-Attention 产生联合局部描述子与质量 logits。离线 MegaDepth 教师通过几何可见性和 LoMa 正负描述子间隔构造；训练用密集 BCE 直接监督质量头，三轮采样只读取一次静态质量图。

**技术栈：** Python 3、PyTorch、NumPy、Pillow、现有 MegaDepth 几何读取、冻结 DINOv2、冻结 LoMa。

## 全局约束

- 输入固定 `518×518`；管理 Patch 为 `16×16`；每 Patch 质量格为 `8×8`；全图质量图为 `128×128`。
- DINOv2 与 LoMa 主干始终冻结；只训练 Patch 语义/价值网络与新增局部网络。
- 不实现 Patch 对、Top-K 候选池、NMS、锚点邻域采样、候选点状态、dustbin、RANSAC、相对位姿损失或连续偏移。
- 每图每轮 1024 点；首轮每 Patch 4 点；第二轮最低 1 点；第三轮可为 0；每 Patch 上限 20。
- 同轮同 Patch 非锚点从 64 个质量格按质量 softmax 无放回采样；跨轮恢复全部 64 格；格内采样连续坐标。
- 同一图像对的质量图在三轮中保持静态，轮间变化只来自锚点、Patch 预算和新的随机采样。
- 总损失为 `L_total = L_base + L_quality`，其中 `L_base` 是三轮 `L_match + L_value` 的平均；暂不加入相对位姿损失。
- 新增文档、注释、docstring、CLI 帮助均为中文；缓存、数据、权重和 `outputs/` 不提交 Git。
- v0.2 检查点包含局部网络，不能由 v0.1 推理入口加载。
