# 37×37 旧三轮训练对照 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不使用 DaD 或完整 LoMa 匹配器的前提下，训练并评测 37×37、1024 点、三轮的旧式 PASM 联合语义模型。

**Architecture:** 保持 `PasmV0` 的三轮直接点边权流程和 `L_match + L_value` 不变。仅新增显式配置，令首轮从 1369 个 Patch 中无放回选择 1024 个、每 Patch 1 点；训练复用原始 `train.train_model`，推理复用 `infer.py` 的 `iterative_loma` 路径。

**Tech Stack:** Python 3.12、PyTorch、NumPy、MegaDepth、冻结 DINOv2、冻结 LoMa DeDoDeDescriptor、unittest。

## Global Constraints

- 不实例化或调用 `FrozenDaDDetector`、`select_patch_budgeted_points`、`FrozenLoMaMatcher`。
- 不使用 v0.4 教师缓存、质量头或 `value_only`。
- 仅训练 `PairSemanticEncoder`；DINO 与 LoMa 描述子冻结。
- 518×518，37×37 Patch，1024 点/图/轮，3 轮；Patch 上限 20。
- 后两轮允许 Patch 预算为 0；几何阈值 6 px，几何支持间隔 2 px。
- 现有 v0.3 / v0.4 DaD 路径不能改变。

```python
def test_legacy_37_pipeline_runs_three_rounds_without_dad(self):
    config = legacy_iterative_37_config()
    runner = PasmV0(PairSemanticEncoder(token_dim=8, hidden_dim=8, heads=2), config)
    result = runner.run(
        torch.randn(1, 1369, 8), torch.randn(1, 1369, 8),
        np.random.default_rng(1).normal(size=(4, 8, 8)).astype(np.float32),
        np.random.default_rng(2).normal(size=(4, 8, 8)).astype(np.float32), seed=3,
    )
    loss = sum(record.edge_weights.mean() + record.patch_values_a.mean() for record in result.rounds)
    loss.backward()

    self.assertEqual(len(result.rounds), 3)
    self.assertTrue(all(len(record.points_a) == 1024 for record in result.rounds))
    self.assertIsNotNone(runner.semantic_encoder.projection.weight.grad)
```
