# PASM v0.3 留出几何评测与 Patch 热图实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 v0.3 的 `dad_global` 与 `pasm_dad` 添加一个一次加载模型、评测固定 9 组严格训练图像外同场景图像对的命令，并输出几何指标、Patch 预算热图和共同可见几何支持热图。

**Architecture:** `pasm_v0/evaluate_v03.py` 独立复用冻结 DINOv2、DaD、完整 LoMa、PASM 价值头和现有几何函数；它不会调用深度或相机数据改变模型输出，只在每组匹配完成后用于统计。`pasm_v0/heldout_v03_pairs.json` 只保存 0285 场景相对图像名；运行时由 `--image-root` 拼成 RGB、EXR 和相机路径。

**Tech Stack:** Python 3.12、PyTorch、NumPy、Pillow、CSV、现有 MegaDepth EXR/Safetensors 几何读取、已安装 loma。

## 全局约束

- 评测固定 `518×518`、`16×16` Patch 网格、每图 1024 点、Patch 上限 20；不修改任何训练、v0.2 三轮或 v0.3 选点决策。
- 固定评测图像必须不在 `--training-manifest` 中所有正图像对的任一侧；重叠必须在推理前 `ValueError`。
- `dad_global` 与 `pasm_dad` 都使用同一个冻结 DaD、同一个完整 LoMa-B128；仅后者运行 DINOv2 + PASM 静态预算。
- 深度、内参、位姿只用于 `geometry_support` 和几何统计，绝不参与 PASM 预算、DaD 选点或 LoMa 匹配。
- 每个方法每组输出各自的 `result.npz`、`points.png`、`matches.png`、`high_confidence_matches.png`；每组再输出四张 Patch 热图与 `patch_values.npz`。
- 几何统计固定 3px/6px，LoMa 高置信阈值固定 0.6，Patch 几何支持网格步长默认 8px，默认最多处理固定 9 组。
