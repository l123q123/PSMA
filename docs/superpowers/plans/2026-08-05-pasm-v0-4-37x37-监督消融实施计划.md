# PASM v0.4 37×37 监督消融 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现可复现的 v0.4 37×37 静态 PASM A/B 监督消融：几何共同可见性真值与 stride=2 LoMa 质量教师真值只切换 Patch 价值监督，其他训练和评测因素固定。

**Architecture:** `config.py` 提供独立 37×37 静态配置；`v04_targets.py` 负责离线目标生成和读取；`train_v04.py` 只训练双图语义编码器，并从缓存取 A/B 的 `L_value` 目标；`evaluate_v04.py` 复用静态 PASM+DaD+LoMa 评测过程并额外汇总预算分布。旧 v0.3 入口和配置不改。

**Tech Stack:** Python 3.12、PyTorch、NumPy、Pillow、tqdm、本地 DINOv2 / DaD / LoMa 权重、MegaDepth 深度与位姿。

## Global Constraints

- 固定输入 `518×518`、37×37 管理 Patch、总点数 1024、单轮、每 Patch 预算 0～4、预算指数 1.0。
- A/B 只允许 `--target-kind` 改变 Patch 价值真值；`L_match`、随机种子、优化器、数据、DaD、LoMa 和 held-out 图像对不变。
- 两种离线目标均使用 `stride=2`；质量教师需真实重新计算，不得读取低密度缓存插值。
- 所有新函数、文件头和函数注释使用简洁中文；不添加与实验无关的模块或测试。
- 不修改既有 v0.3 代码路径的行为；v0.4 使用新的命令入口和输出目录。
