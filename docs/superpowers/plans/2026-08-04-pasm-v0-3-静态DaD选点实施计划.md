# PASM v0.3 静态 DaD 选点实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** 在不重训 PASM 的前提下，提供 dad_global 与 pasm_dad 两个单轮推理模式，以 DaD 在整图或 PASM 静态 Patch 预算内选择 1024 个点，再交给冻结完整 LoMa-B128 匹配。

**Architecture:** pasm_v0/dad.py 只负责本地权重的冻结 DaD 推理与从稠密分数/NMS 候选中按 Patch 预算无重复选点。pasm_v0/loma_matcher.py 只负责给外部指定坐标提 LoMa 描述并运行完整 LoMa Transformer 匹配。infer.py 只负责模式路由、PASM 预算和统一保存。

**Tech Stack:** Python 3.12、PyTorch、NumPy、Pillow、已安装的 loma、本地 DINOv2 / DaD / LoMa 权重。

## 全局约束

- 输入固定缩放到 518×518，Patch 管理网格固定为 16×16。
- pasm_dad 每图恰好 1024 点，预算范围为 0～20；实际每 Patch 点数必须等于 PASM 分配预算。
- DaD 使用原生 3×3 NMS 与亚像素坐标；某 Patch 的 NMS 点不足时，才按该 Patch 内的稠密 DaD 分数降序，以像素栅格中心补齐。
- 所有输出点必须在 [0, 518)、不重复；pasm_dad 的点 Patch ID 必须与坐标归属一致。
- dad_global 不读取 PASM 预算；pasm_dad 使用 v0.2 检查点价值头计算一次静态预算，不使用锚点、反馈、重采样或三轮输出。
- DaD、LoMa 必须从命令行给出的本地 .pth 读取；推理不触发网络下载；DINOv2、PASM、DaD、LoMa 均冻结、eval、inference_mode。
- 保留 static_semantic 与 iterative_loma；不改训练、质量教师和 v0.2 三轮流程。
