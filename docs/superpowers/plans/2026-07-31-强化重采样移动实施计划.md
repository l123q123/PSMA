# PASM v0.1 强化重采样移动实施计划

> **供执行代理使用：** 按测试驱动顺序实施；项目当前不在 Git 仓库中，不创建工作树或提交。

**目标：** 在不改变总点数、Patch 上限、轮数或匹配结构的前提下，让自由采样预算更明显地向高价值 Patch 迁移。

**架构：** 提高锚点阈值以减少中等置信锚点的原样保留；在完成锚点保留预算后，对剩余预算分配分数做二次幂锐化；扩大 Patch 内扰动半径。`round_min_points=(4,1,0)` 保持不变，防止第二轮因偶然失配过早淘汰区域。

**技术栈：** Python、NumPy、PyTorch、unittest。

## 全局约束

- 默认总点数保持 1024，每 Patch 上限保持 20。
- 冻结 DINOv2 与 LoMa；不新增 Patch 对或专门匹配器。
- 所有注释与文档使用中文。
- 预算锐化仅影响锚点保留后的增量分配，不影响锚点的保留坐标和最低预算。
