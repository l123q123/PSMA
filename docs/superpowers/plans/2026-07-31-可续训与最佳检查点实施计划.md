# PASM v0.1 可续训与最佳检查点实施计划

> **供执行代理使用：** 依次执行每项测试驱动步骤；项目当前不在 Git 仓库中，不创建工作树或提交。

**目标：** 每轮保存可精确续训的最后训练状态，并仅在平均 loss 降低时更新最佳模型检查点。

**架构：** `输出.pt` 保存最低平均 loss 对应的模型、优化器和该轮历史；`输出.last.pt` 在每个完成的 epoch 后覆盖保存最新状态，用于继续训练。`--resume` 读取保存的 epoch、历史和优化器状态；兼容旧检查点，只加载模型权重并读取同名历史文件确定已完成轮数。

**技术栈：** Python、PyTorch、unittest、JSON。

## 全局约束

- 所有文档和代码注释使用中文。
- 续训时 `--epochs` 表示目标总轮数，而非新增轮数。
- 不修改 DINOv2、LoMa、匹配、采样或损失计算。
- 最佳模型按每轮完整训练集的平均 loss 比较。
